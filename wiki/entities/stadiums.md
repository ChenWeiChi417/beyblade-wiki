# 戰鬥陀螺 X 官方戰鬥盤場地介紹

> **TL;DR（簡明摘要）**：**BX-10 極限衝擊戰鬥盤**是戰鬥陀螺 X（Beyblade X）的官方標準競技場地。場內不僅內建與軸心（Bit）齒輪咬合的**極限軌道（Xtreme Line）**，角落與正中央更配置了決定 2 分與 3 分勝負的**擊飛區（Over Zone）**與**極限區（Xtreme Zone）**。

## 代表性官方場地：BX-10 極限衝擊戰鬥盤

- **商品編號與名稱**：`BX-10 極限衝擊戰鬥盤`
- **所屬系列**：[BX 系列（Basic Line）](../series/bx-series.md)
- **場地定位**：戰鬥陀螺 X 官方標準競技場地，內建專用的極限軌道結構，是體驗「Gear Sports（齒輪運動）」高速對戰與舉行 [3on3 Deck 官方賽制](../concepts/3on3-deck.md) 的核心周邊。
- **其他戰鬥盤型號**：**待補充**。

## 戰鬥盤三大關鍵結構與計分區域

根據基礎機制與官方計分規則，極限戰鬥盤內部包含以下三個直接影響戰術與得分的關鍵區域：

| 場地結構／區域 | 位置說明 | 核心功能與計分判定 |
| :--- | :--- | :--- |
| **極限軌道（Xtreme Line）** | 鋪設於極限戰鬥盤內側 | 當陀螺底部的**軸心（Bit）**齒輪與軌道咬合時，會觸發超高速加速並切入盤心猛烈撞擊的 [極限衝刺（Xtreme Dash）](../concepts/xtreme-dash.md) |
| **擊飛區（Over Zone）** | 位於戰鬥盤角落區域 | 將對手陀螺撞入此區域，即達成**擊飛獲勝（Over Finish）**，獲得 **2 分** |
| **極限區（Xtreme Zone）** | 位於戰鬥盤正中央區域 | 將對手陀螺撞入此區域，即達成最高分的**極限獲勝（Xtreme Finish）**，直接獲得 **3 分** |
